# E-commerce Data Analysis

## Project Overview
This project analyzes e-commerce data to identify business trends and generate useful insights using Python, SQL, and Power BI.

## Tools Used
- Python: Pandas for data cleaning and Matplotlib for visualization
- SQL: Data validation and business queries
- Power BI: Interactive dashboard and visual reporting

## Project Workflow
1. Imported the dataset into Python.
2. Cleaned and prepared the data using Pandas.
3. Loaded the cleaned data into SQL for validation and analysis.
4. Analyzed the data using SQL queries.
5. Created charts and an interactive Power BI dashboard.

## Key Challenges
Data cleaning, checking missing values, and ensuring data consistency before analysis.
